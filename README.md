# 北京学生体测计算器

一个零依赖、纯前端的北京四、六、八年级体质健康统测成绩估算工具。

选择年级和性别后，输入测试成绩即可查看：

- 国家学生体质健康标准的单项成绩与加权标准分；
- 跳绳（小学）或力量与耐力（八年级）的附加分；
- 国标测试总分（上限 120 分）；
- 北京统测折算的 10 分制成绩；
- 八年级可选的体育与健康知识机考合计估算。

## 使用

这是一个静态页面，无构建步骤、无第三方依赖。

直接在浏览器打开 `index.html`，或使用任何静态文件服务器托管该目录即可。

所有输入值只保存在访问者自己的浏览器 `localStorage` 中；页面不会上传或收集成绩数据。

## 计分依据与边界

评分阈值、权重和附加分规则依据下列公开资料整理：

- [北京市四、六、八年级体测说明](https://www.beijing.gov.cn/fuwu/bmfw/sy/jrts/202607/t20260717_4768909.html)
- [北京市义务教育体育与健康考核评价方案](https://www.beijing.gov.cn/zhengce/gfxwj/202112/t20211209_2557431.html)
- [《国家学生体质健康标准（2014年修订）》](https://www.cap.edu.cn/tyjxb/info/1251/12582.htm)

本项目仅供个人学习和成绩估算，不代替学校或区级统测记录；正式成绩请以学校最终认定为准。
